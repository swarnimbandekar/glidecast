# Contributing to Glidecast

Thanks for helping! Bug reports, ideas and pull requests are all welcome.

## Getting started

1. Install the [.NET 8 SDK](https://dotnet.microsoft.com/download) and FFmpeg
   (`winget install Gyan.FFmpeg.Essentials`).
2. `dotnet build Glidecast.sln`
3. `dotnet run --project src/Glidecast` — or try the engine headless with
   `dotnet run --project src/Glidecast.Cli -- demo .\demo`.

Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for a tour of the code.

## Pull requests

- Keep changes focused; one feature or fix per PR.
- Match the surrounding style (C# 12, nullable on, file-scoped namespaces,
  comments that explain *why*).
- Make sure `dotnet build Glidecast.sln -c Release` passes with no new warnings.
- For UI changes, include a before/after screenshot.
- For timing, camera or cursor changes, describe how you checked sync
  (e.g. a recording rendered with `glidecast-cli render`).

## Reporting bugs

Open an issue with your Windows version, display scaling, what you recorded
(full screen / region, fps), and what you expected. If you can, attach the
project's `project.json` (it contains mouse/keyboard events, so check it
first for anything private you typed).

## Branding

The logo and icons are generated by `tools/BrandKit` — see
[docs/BRANDING.md](docs/BRANDING.md). Please don't hand-edit files in `assets/`.
